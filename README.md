# The Long Roast: Lawmakers and the File They Cannot Convert

A one-sentence satirical roast entry for the make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert". The program `main.py` writes a single sentence to `/output/entry.txt` — lawmakers who passed a 400-page bill to regulate artificial intelligence, then asked their intern to explain the difference between a PDF and a printer.

> They passed a 400-page bill to regulate artificial intelligence, then asked their intern to explain the difference between a PDF and a printer.

Run it with `python3 main.py`. It asserts the entry is 1–320 characters, exactly one sentence (one terminal period, no other sentence-ending punctuation), a single line with no leading or trailing whitespace, then writes it with no trailing newline.
